# Changelog

## [1.0.0] — 2026-10-06

Первый выпуск.

- Портативный `Phosphor.exe` на .NET Framework 4.8 + WPF, без установки.
- Пакетная тихая установка через `winget`, строго по очереди, с прерыванием после текущего пакета.
- Встроенный каталог: 85 пакетов в 10 категориях, id сверены с winget-pkgs.
- Редактируемый `apps.json` рядом с exe, перечитывание по F5, fallback на встроенный каталог.
- Поиск по всем категориям, счётчики выбранного, статусы в строках.
- Журнал в окне и в `logs\*.log`, прогресс на значке в панели задач.
- Перезапуск с правами администратора с сохранением выбора.
- Командная строка: `--select id1,id2 [--install]`.
